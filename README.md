# FoundIt - Lost & Found Web App

**FoundIt** is a full-stack web application that allows users to report, search, and manage lost and found items. It provides a streamlined interface for users to post lost items, browse found listings, and reconnect with their belongings.

---

## Features

* Report lost or found items with images and details
* Search and browse listings
* User authentication and profile management
* Feedback submission system
* Dark mode support
* FAQ section for user guidance

---

## Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Image Uploads:** Cloudinary
* **Deployment:** Render

---

## Getting Started

### Prerequisites

* Node.js (v14 or higher)
* npm
* MongoDB (local or cloud-based)
* Cloudinary account (for image uploads)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/foundit.git
cd foundit

# Install backend dependencies
npm install

# Set up client
cd client
npm install
cd ..

# Create environment variable files
# .env (for backend)
# .env (inside /client for frontend)
```

### Run the App (Development)

```bash
# Start backend and frontend concurrently
npm run dev
```
